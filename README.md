📦 Sistema de Orçamentos para Etiquetas

Aplicativo móvel criado em React Native para registro de usuários e administração de orçamentos de etiquetas.

🚀 Recursos
Autenticação e registro de usuários
Armazenamento de dados persistente com AsyncStorage
Registro de orçamentos
Cálculo automático do montante total
Exibição de orçamentos armazenados
🛠 Tecnologias
React Native
JavaScript
Armazenamento assíncrono
▶️ Implementação
npm install
npm install @react-native-async-storage/async-storage
npx react-native run-android
